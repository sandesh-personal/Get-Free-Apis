# GetFreeAPIs

Directory of 2,700+ free public APIs, filtered by auth requirements, CORS support and HTTPS.
Built with Next.js and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Scripts

- `npm run data` — rebuild the API catalogue from sources
- `npm run health` — check API endpoint uptime
- `npm run lint` / `npm run lint:mdx` — lint code and blog content
